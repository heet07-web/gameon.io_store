# GameOn.io V3

Modern cricket e-commerce frontend built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in Chrome or use VS Code + Live Server.

## Main pages
- `index.html`
- `product.html`
- `aboutus.html`
- `contactus1.html`
- `buynow.html`

## Assets
New generated GameOn visuals are included in `assets/`.

## JavaScript features
- product rendering
- search/filter/sort
- wishlist
- cart with localStorage
- quantity controls
- product modal
- checkout validation
- contact form validation
- mobile navigation
- toast notifications
- reveal animations
